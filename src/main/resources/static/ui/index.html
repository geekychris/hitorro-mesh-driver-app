Add distributed table (runtime registration)

Driver-side metadata only

Agents must already hold this table's data AND advertise each partition's required capability. If they don't, queries against this table will fail with "no live agent has capabilities…". In-memory only — lost on driver restart; use YAML config for prod.

Auto-derives capabilities as [jvssql, partition:<table>:<key>]. For custom capabilities, use the API directly (see docs).

Add broadcast table (runtime registration)

Name registration only

Registers the broadcast NAME with the driver's planner so JOINs to it are allowed. Every agent must independently pre-load the broadcast data via its own hitorro.mesh.agent.broadcast-tables config — the driver doesn't distribute the data.
