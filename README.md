# Hitorro Mesh Driver App

Spring Boot deployable for the Hitorro Mesh driver — wires MeshDriver + REST API + management UI + auto-configured MeshTransport + ClusterManager into a single fat jar you can drop onto any host, Kubernetes pod, or Orion node.
